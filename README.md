# Rimario

Cuaderno de barras para escribir rap: mide sílabas, detecta rimas consonantes y asonantes, tiene retos diarios, niveles, títulos, personajes animados y música.

**Beta 1.0** · hecho por [@facunnn_fb](https://www.instagram.com/facunnn_fb/)

## Cómo usarla
Abrí la página en Chrome (Android) y tocá **Instalar Rimario** en Ajustes, o el menú de los tres puntos y **Agregar a la pantalla principal**. Después anda sin internet. Tus textos se guardan solo en tu celu.

## Para quien edite el código
Es una sola página (`index.html`) más `sw.js` y `manifest.webmanifest`. Cada vez que cambies archivos, subí `VERSION` en `sw.js` para que los celus se actualicen.
